## 📌 Overview

This repository contains the source code for the personal developer portfolio of **Siddharth Bharti** — **Java Backend Developer | Spring Boot | Microservices Specialist**.

Built with **React 19** and **Vite**, this application features a sleek dark mode design system, smooth glassmorphism UI components, interactive modals for deep project architecture reviews, dynamic resume preview with confetti animations, and full mobile responsiveness.

---

## ✨ Key Features

* **🎨 Sleek Dark Aesthetic**: Styled with custom CSS tokens, modern glassmorphism panels, gradient text highlights, and subtle micro-animations.
* **🚀 Deep Project Showcase & Architecture Modals**: Interactive detail modal allowing visitors to inspect system architecture designs, microservices components, database schemas, and feature lists.
* **📄 Interactive Resume Modal**: Integrated modal previewing career experience, MCA education details, and instant download actions with celebratory confetti effects (`canvas-confetti`).
* **💻 Comprehensive Tech Stack Categorization**: Visual progress meters categorizing Java, Spring Boot, Microservices, PostgreSQL, Kafka, Docker, Kubernetes, and Observability tools (ELK, Zipkin, Prometheus).
* **⚡ Single Source Data Architecture**: All content is centralized in `src/data/portfolioData.js` for easy updates and maintainability.
* **📱 Fully Responsive**: Seamless layout adaptivity across desktop, tablet, and mobile displays.

## 💻 Local Development Setup

### Prerequisites
* **Node.js** (v18 or higher recommended)
* **npm** or **yarn**

### Quick Start
1. **Clone the repository**:
   ```bash
   git clone https://github.com/Sid0305/SidPortfolio.git
   cd SidPortfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Preview production build locally**:
   ```bash
   npm run preview
   ```

## 🌐 Deployment

This application is optimized for one-click deployment on **Vercel**.

The repository includes a `vercel.json` routing configuration to handle Single Page Application (SPA) re-writes:
```json
{
  "rewrites": [
    { "source": "/(.*)", "destination": "/" }
  ]
}
```
